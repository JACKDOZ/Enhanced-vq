# Enhanced VQ

> *Explore the world. Follow your journey. Complete the adventure.*

Enhanced VQ (Enhanced Vanilla Quests) is a vanilla-friendly quest and progression mod for Minecraft designed to give players a clearer sense of adventure and purpose throughout their journey.

From the first days of survival to the most challenging moments of the game, Enhanced VQ introduces objectives, milestones and progression systems that encourage players to explore the world, discover its creatures and experience Minecraft in a more structured way.

The mod expands the vanilla experience without replacing its identity. Every quest and system is designed to feel naturally connected to Minecraft's world, survival mechanics, exploration and combat.

Version 0.9.5 continues improving the overall experience with visual upgrades, a new 3D Quest Book, improved player feedback and multiplayer compatibility, while building upon existing systems such as the Warrior quests, Bestiary and overall progression tracking.

---

# 📥 Installation

Enhanced VQ requires:

* Minecraft Java Edition
* Fabric Loader
* Fabric API

### Installation Steps

1. Install Fabric Loader for your Minecraft version.
2. Download and install the required version of Fabric API.
3. Download the latest version of Enhanced VQ.
4. Place the mod `.jar` file inside your Minecraft `mods` folder.
5. Launch Minecraft using the Fabric profile.

# 🛠️ Building from Source

This repository contains the source code for Enhanced VQ.

### Requirements

* Java Development Kit (JDK)
* Compatible Minecraft development environment

### Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Enhanced-VQ.git
cd Enhanced-VQ
```

### Build

Windows:

```bash
gradlew.bat build
```

Linux/macOS:

```bash
./gradlew build
```

After a successful build, the compiled mod will be located in:

```text
build/libs/
```

# ✨ Main Features

### 📖 Quest Book

Access your quests, objectives and progression through a dedicated Quest Book that now features a real 3D Minecraft model.

### ⚔️ Warrior Quests

A dedicated combat progression category featuring quests related to Minecraft's creatures and enemies.

### 📘 Bestiary

Discover and track creatures encountered throughout your adventure. The current Bestiary includes 44 different Minecraft creatures.

### 📊 Progression System

Follow your overall progress and discover how much of your adventure remains to be completed.

### 🎁 Quest Rewards

Complete objectives and claim rewards as you progress through your Minecraft journey.

### 🌍 Vanilla-Friendly Design

Enhanced VQ expands Minecraft without changing its core identity, keeping exploration, survival and discovery at the center of the experience.

### 👥 Multiplayer Compatible

Play, complete quests and progress through the adventure together with your friends.

### 🔊 Improved Player Feedback

Version 0.9.5 introduces improved visual and sound feedback to make interactions, progression and reward claiming more satisfying.
